Entry for make.fun's **"The Meeting That Should Have Been an Email"** bounty ($2 in USDC).
One joke line about a meeting that should have been an email — no code, no
attachments, no second line. The line is the whole entry.

## The entry

> We scheduled a meeting to discuss the email, then emailed a recap of the meeting about the email. Attendance: everyone. Attention: no one.

(138 characters, one line.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

`main.py` writes exactly that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and
prints it. Fully deterministic, exit 0.
